# Beyond software

The stages are not specific to code. Each one has an older name in project management, lean
manufacturing, operations or auditing (see the [terms crosswalk](09-why-it-works.md#terms-crosswalk)),
so the method applies wherever work can be cut into items with a checkable result. Software is
where AI agents are most capable today, but agents can already draft, research, compare and
check documents in most kinds of project.

Everything on this page is an untested proposal: the method has only been run on a software
project ([case study](08-case-study.md)).

## The stages in three other kinds of project

| Stage | House renovation | Compliance audit | Event or office move |
|---|---|---|---|
| 0 AI stance | Which documents and photos of the house may be shared with AI tools | Which evidence may enter AI tools; no personal data without approval | Which contracts and staff data may be shared with AI tools |
| 1 Situation analysis | Survey the house as it is against the drawings | Current controls against the standard | Inventory of people, assets and contracts |
| 2 Context file | Budget, style, what must not change | Scope, framework, evidence rules | One brief for all suppliers |
| 3 Roles | One trade per room; an inspector who doesn't build | Control owner and independent tester | One owner per workstream, a separate reviewer |
| 4 Phased plan | Permits and long-lead materials first | Requests to other departments first | Venue, permits and catering first |
| 5 Backlog | One job per row, with its test | One control per row, with evidence | One deliverable per row, with acceptance criteria |
| 6 Work isolation | Seal off each room | One evidence folder per control | One channel per workstream |
| 7 Standard procedure | Inspect, plan, sign off, do, test, photograph, tick | Review, test, check, file, mark | Confirm, book, get written confirmation, mark |
| 8 Status verification | Done only with a certificate or photo | Done only with dated evidence | Done only with written confirmation |
| 9 Retrospective | Update the brief when the client changes their mind | Re-baseline when the standard changes | Review the checklist after each event |

AI sits in the same place in every column: it drafts, does and reviews work in parallel, while
people approve the gates and decide what counts as evidence.

## Walkthrough: an office move

A company of 60 people moves to a new floor in eight weeks. One operations lead runs it, with AI
assistants for drafting, comparing quotes and chasing confirmations.

**Week 1.**
1. *AI stance (stage 0).* The lead agrees with management which material may go into AI tools:
   floor plans and supplier quotes yes, staff home addresses and contract salaries no.
2. *Situation analysis (stage 1).* An AI assistant builds an inventory from the asset register,
   the current lease and a staff survey. The lead checks it against a walk-through of the old
   office. Two server cabinets are missing from the register. That changes the plan, because they
   need a specialist mover.
3. *Context file (stage 2).* One page that every helper, human or AI, gets first: move date,
   budget, the rule that the network must be up before people arrive, the rule that nothing is
   ordered without a written quote, and who approves what.

**Week 1 to 2.**
4. *Phased plan (stage 4).* Long-lead items go first: the building's permit for the lift, the
   network provider's installation slot, the specialist mover. All three requests go out in week 1
   as one bundle.
5. *Roles (stage 3).* One owner each for IT, furniture, facilities and communications. Finance
   reviews every order but does not place any.

**Week 2 to 7.**
6. *Backlog (stage 5).* Each row is one deliverable with its acceptance criteria and the
   evidence it needs, for example "network live on floor 4: a speed test from three desks,
   screenshot attached".
7. *Work isolation (stage 6).* Each workstream has its own folder and channel; nobody edits
   another workstream's orders.
8. *Standard procedure (stage 7).* After running the first few supplier bookings by hand, the
   lead writes down the routine: get a quote, check it against the budget, get approval, book,
   get written confirmation, record it. AI assistants then run that routine for the remaining
   bookings, stopping at the approval step.

**Week 3 onward.**
9. *Status verification (stage 8).* A row is done only with written confirmation or a photo. A
   weekly check flags any done row without one. In week 5 it catches a furniture delivery marked
   done from the supplier's own tracking page, with no delivery note: "a system reporting its own
   success is not evidence" applies here too.

**After the move.**
10. *Retrospective (stage 9).* The checklist and the context page are updated with what went
    wrong, so the next move starts from a better standard.

The walkthrough is illustrative. The numbers and events are invented to show the stages, not
taken from a real move.
